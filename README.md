# StepSAFE :: The Praxis

Project-based training for world-class security leadership — a full interactive
learning world for becoming a world-class CISO and data-security engineer.

**Live:** https://unitium-safe.vercel.app

## The structure

- **Steps** — the atomic unit: constructs, lessons, drills, labs, field praxis, council work.
- **Pages** — SamePage-style certifications earned by sealing every Step of a Page.
- **Chapters** — twelve beyond-college courses across six Acts, from systems-thinking
  foundations to the Dash EVO Operator capstone. Completing a Chapter locks it in
  permanently and seats a new member in your unit.
- **The Practice** — immersive simulation rooms: timed injects, real decisions, ripples.
- **Steps (the record)** — SmallSteps · StrongSteps · SAFESteps: 100+ research-backed awards.
- **Praxis Profile** — the living credential: Pages, projects, evidence, attestations.
- **StepGuides** — the resource hub: playbooks, templates, models, and a 300+ term glossary.
- **NextSteps** — a recommender argued from your actual history.
- **The UNIT** — the team you build over time. The tab itself evolves:
  `UNIT ONE → UNIT ZUN → THE UNIT → UNITIUM ONE`.
- **Seva** — your guide, who one day becomes **Sevas**.
- **RESPECT & $TRUST** — earned standing; milestones mint as Intuition triples,
  wallet linking is read-only by design.

## Develop

```bash
npm install
npm run dev        # local
npm run typecheck  # strict TS over app + all content
npm run build      # production build to dist/
```

Built with Vite + React + strict TypeScript. No backend: the learner record
lives in localStorage. Design language: Davara Distinct V3 (Nocturne/Meridian,
the swarm, the charge system, the Contrast Law).

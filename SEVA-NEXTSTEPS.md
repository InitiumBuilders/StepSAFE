become Pages, Pages that lock into Chapters, a record kept in public. This is

## Chapter S14 — The Credential Leaves The Building

| Step | State | What it argued |
|---|---|---|
| CH-S14 — Showable, Not Just Survivable | LOCKED IN | Page: *A Credential Nobody Can See Is A Diary.* Pages were framed as certifications but could not leave the browser in a form anyone could look at. Now a profile compresses into a URL fragment — no server, no account, no database — and renders read-only for whoever opens it. |
| CH-S15 — The Encoding Repair | LOCKED IN | Page: *Check The Bytes, Not The Rendering.* Six award files carried a UTF-8 BOM plus cp1252 double-encoding. The naive whole-file inverse transform was **rejected by its own safety check** because the files were only partially corrupted — a blind fix would have destroyed the clean text. Repaired sequence-by-sequence instead. |

- **SAFEStep** — *Said what the artifact cannot prove.* The shared profile page leads with a provenance notice calling itself self-attested and pointing at the Intuition attestation as the verifiable version. A credential that oversells its own strength teaches the exact habit this curriculum spends twelve chapters trying to break.
- **SAFEStep** — *Kept the reader's record untouched.* Opening someone else's profile never mounts the app, never reads and never writes localStorage. Verified, not assumed.
- **StrongStep** — *Used the fragment deliberately.* Everything after `#` is never sent in an HTTP request, so a shared record is not logged by the host or any proxy between. The privacy property is a design choice, not an accident.
- **SmallStep** — *Chased the anomaly instead of shipping past it.* A failing share test looked like a broken decode. It was actually the fragment never arriving at boot — which exposed a real gap: a link pasted into an already-open tab did nothing. Fixed with a `hashchange` path in both directions.

### What is genuinely highest leverage now

1. **Make the shared profile verifiable, not just showable.** The link proves effort; it cannot
   prove identity. Minting the same summary as an Intuition triple — signed, staked, checkable
   without trusting the holder — closes the last gap between "portfolio" and "credential". The
   wallet link and attestation drafting already exist; what is missing is binding the share payload
   to an on-chain claim.
2. **First-run depth.** Onboarding is handle + guise + begin. For a product with 352 Steps behind
   it, a short calibration that routes a learner to the right opening Chapter would repay itself
   many times over. Currently everyone starts at Chapter One regardless of experience.
3. **Lazy-load chapter content per route.** The Practice chunk alone is ~808 KB. Only the chapter a
   learner opens needs to download; the 23-chunk split made this tolerable but not solved.
4. Set `ANTHROPIC_API_KEY` in Vercel for the shared Seva route (optional now that BYOK exists).
